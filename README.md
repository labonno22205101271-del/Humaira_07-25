# Humaira Akhter Labonno — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository, e.g. `humaira-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the published website URL shown in the Pages section.
